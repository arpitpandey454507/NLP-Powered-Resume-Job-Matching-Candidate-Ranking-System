# Deployment Guide

This guide explains how to deploy the NLP-Powered Resume–Job Matching & Candidate Ranking System.

## 🌐 Deploy Using Streamlit Community Cloud

### 1. Push the Project to GitHub

Make sure the complete project is available in a GitHub repository.

### 2. Open Streamlit Community Cloud

Go to:

https://share.streamlit.io/

Sign in using your GitHub account.

### 3. Create a New App

Select:

**Create app → Deploy a public repository**

Choose your GitHub repository and select the branch containing the project.

### 4. Select the Main File

Set the main application file to:

```text
app.py
